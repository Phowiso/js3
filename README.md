# МебельДом — магазин мебели на Next.js

Учебный проект: простой каталог мебели.

## Возможности

- Каталог товаров (плитка карточек)
- Страница товара с описанием
- Данные в отдельном файле

## Запуск

```bash
npm install
npm run dev
```

Открыть: http://localhost:3000
